## 첫 단계: 사진 해석 실험

- [ ] 새 노트북의 Python, GPU 모델명, VRAM 확인 (`nvidia-smi`가 사용 가능하면 확인)
- [ ] 사진 3~5장과 촬영 시각 준비, 기대하는 일기 직접 작성
- [ ] 사진 해석 모델 후보 선택과 실행 방법 확인
- [ ] `ai/experiments/`에서 사진 한 장을 해석하는 최소 실험 작성
- [ ] 관찰하지 못한 내용을 지어내는지, 한국어 품질, 처리 시간, 메모리 사용 확인

완료 기준: 같은 사진으로 해석을 재실행할 수 있고 입력·결과·모델 설정·처리 시간·실행 명령을 기록합니다. 외부 API로 먼저 연결해도 되지만 직접 모델 배포 경험을 위한 후속 작업을 남깁니다.

## 두 번째 단계: 하루 일기 생성

- [ ] 사진별 해석 결과와 시각을 묶어 일기 한 편 생성
- [ ] 입력에 없는 사건을 추가하지 않는 생성 규칙 마련
- [ ] 강아지 사진은 강아지 말투, 사람 데이터 실험은 사람 시점으로 검증
- [ ] 모델·프롬프트 버전 및 분석 결과 저장 형식 정의

완료 기준: 사진 3~5장으로 대표 장면을 포함한 일기 한 편이 생성되고 어떤 사진에서 나온 내용인지 추적할 수 있습니다. 강아지 검증 데이터가 없으면 감정 정확도를 검증했다고 쓰지 않습니다.
